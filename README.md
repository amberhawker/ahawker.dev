# ahawker.dev

Personal portfolio site for Amber Hawker — software & systems developer, IT specialist.

Built with [Next.js](https://nextjs.org) (App Router), TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev     # http://localhost:3000
```

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Content

All site copy lives in `src/content/site.ts` — contact details, services, projects, and
skills are edited there rather than in the components.
