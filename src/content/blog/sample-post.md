## Adding a post

Create a Markdown file in `src/content/blog/` with this frontmatter:

```md
---
title: "Post title"
description: "One-line summary shown in the list"
date: 2026-11-19
tags: ["systems"]
private: false # true = only readable after unlocking
draft: false   # true = hidden everywhere
---
```
