This website! I wanted a portfolio that felt like me, so it's styled as a cross between a terminal and a retro desktop. Projects render as README.md files inside mock OS windows, and navigation reads like shell commands.

Under the hood it's Astro with content collections for projects, experience, and blog posts, styled with Tailwind CSS and daisyUI, with anime.js handling animation. It's deployed on Cloudflare Workers through the Astro Cloudflare adapter, which also powers a few on-demand routes behind the otherwise static site.
