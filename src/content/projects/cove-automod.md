CoveAutoMod is a plugin for Cove, a dedicated server for the game Webfishing, that controls how a server handles inappropriate messages. Server owners configure which words trigger which actions, and every action taken can be posted to a Discord channel through a webhook for review.

Players can also use a report command so moderators can keep on top of bad actors.

I made this as a project to learn C# and .NET, as well as to help out my Webfishing community. It is currently supporting the top server in the Webfishing community.
