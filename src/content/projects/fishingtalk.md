FishingTalk connects a Webfishing server running Cove to a Discord channel, letting players and Discord members chat without switching between the two.

In-game messages are relayed to Discord, and messages from Discord appear in the game in real time. The plugin uses a Discord bot and webhook, configured through a JSON file on the server.

This was another project to learn C# and .NET, as well as to help out my Webfishing community. It is currently supporting the top server in the Webfishing community, "happy trans webfihsing". As well, it's shared and used by other servers in the community.
