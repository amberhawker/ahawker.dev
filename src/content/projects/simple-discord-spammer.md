One of my earliest Python projects, back when I was first poking at the Discord API to see what it could do. The only mildly interesting part is that it's async, so it doesn't lock itself up while sending - which is what made it a step up from the usual first attempt at this kind of script.

It's very much an early-learning artifact, kept around because it marks where I started figuring out event loops and concurrency.
