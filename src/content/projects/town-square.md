Built with a team of five for the 2026 Girls in Tech Hackathon, which had the theme of "Bettering Business". Town Square helps local businesses, non-profits, and foundations source products from nearby farms and producers, supporting the local economy through more direct connections between buyers and suppliers.

We spent a weekend building this app, and it was a great learning experience. I learned a lot about working in a team and learned how I can work best under pressure.

The app uses a React and Vite front end with Leaflet maps, backed by a Python and Flask API. Docker Compose runs the front end and back end together for local development, and GitHub Actions provides CI.
